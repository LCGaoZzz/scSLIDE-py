# Changelog

## 0.3.3 — verified core and distribution preparation

Native Python implementation of the 19 upstream scSLIDE capabilities, explicit sample/cell/landmark contracts, named-feature model persistence, dense/sparse and validated H5AD/Zarr paths, exact and optional approximate neighbors, sample geometry, descriptive trajectory associations and figures with source data.

The final approved repair corrects exact-neighbor worker provenance and preserves actionable permission errors for Zarr. The exact audited wheel is identified by build `scslide-py-0.3.3-02043e3c1215`; see `artifacts/manifest.json`. Historical internal candidates with the same version are not interchangeable.

Exploratory OOF, splitting and permutation extensions are explicitly not universal confirmatory procedures. Reference and case validation scope is recorded under `validation/` and `docs/`.

## Standalone repository organization

User-facing documentation, figure gallery, exact artifact copies and necessary synthetic R references are separated from private research history. No numerical implementation changes are introduced by that reorganization. The relocated stored-golden runner has explicit failure exit behavior; validation and CI no longer need internal campaign directories. Current source builds have current documentation and are not byte-identical to older archived distribution ZIPs.
