# Figure and table provenance

PNG/SVG/CSV showcase files and the three synthetic PDFs are copied without changing their bytes from retained project evidence. Public file hashes are recorded in `validation/PUBLIC_SNAPSHOT_MANIFEST.json` and the repository history; the preparation operation is not a new scientific experiment.

`sample_diffusion`, `landmark_umap` and `trajectory_heatmap` were generated by the portable synthetic user task. They do not represent COVID or SEA-AD observations. The task's PNG/PDF/SVG had previously been inspected separately; a copy is not a new independent human review.

`historical_release_acceptance` retains the original backend/resource summary and its CSV. Some panels use absolute correlations and earlier measured builds. The signed trajectory convention, slower Python conditions and non-new-candidate timing scope are explained in the [comparison](../../comparison_with_R.md) and [benchmark](../../benchmark.md) pages.

No patient-level count matrix, individual clinical metadata table or private run log is included in this gallery.
